## What this provisions

- A Cloud Run v2 service (`hello-service`) in `asia-southeast1`
  - `min_instances = 1`, CPU always allocated (so the in-process 5s timer keeps ticking)
  - Internal load-balancer ingress only
  - Startup probe on TCP/8080
- A dedicated runtime service account `hello-run-sa` with least-privilege
  (`logging.logWriter`, `monitoring.metricWriter`, `cloudtrace.agent`)
- A log-based metric counting `hello world` stdout lines
- A Cloud Monitoring uptime check on `GET /hello` every 60 s
- Optional: `roles/run.invoker` for a caller SA passed in via `var.invoker_sa`

## What this does NOT touch

- The VPC `shared-internal-asia` (referenced as a `data` source)
- The Artifact Registry repo `apps` (referenced as a `data` source)
- Org policies, Binary Authorization attestors, custom domains

## How to apply

This directory is opened as a **pull request only**. CI must:

1. `terraform fmt -check`
2. `terraform validate`
3. `terraform plan` (uploaded as a PR comment)

Authentication uses **Workload Identity Federation** — no service-account JSON
keys are committed or stored.
